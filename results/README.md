# What is in `results/`

Every metrics file carries a `_provenance` block naming the corpus, label-space
size, graph construction and split that produced it. **Rows from different
corpora are never comparable**, and `src/evaluate.py` now refuses to place them
in one table.

| File | Corpus | What it holds |
|---|---|---|
| `metrics.json` | whatever was last trained | canonical results for the current corpus; written by `src/train.py` |
| `metrics_synthetic.json` | synthetic (600 tracks, 33 tags) | architecture sanity-check run. **Not** evidence about any Table 1 corpus |
| `metrics_gtzan.json` | GTZAN (999 clips, 10 genres) | baselines only — see the note in its `_provenance` |
| `gnn_depth_sweep.json` | synthetic | Task 2 GraphSAGE depth 1–4; the coherence-saturation investigation |
| `comparison_table.txt/.json` | current corpus | the spec's Table 3, generated by `src/evaluate.py` |
| `history_<run>.json` | current corpus | per-epoch loss + val metrics (the F1-vs-epoch curves) |
| `predictions_<run>.npz` | current corpus | test scores + targets, for PR curves |
| `per_tag_<run>.json` | current corpus | per-tag precision / recall / F1 / support |
| `embeddings_task3_*.npz` | current corpus | fused `z` + genre/mood labels, for t-SNE |
| `task1_examples.json` | current corpus | Task 1 deliverable: 5 predictions with salient tokens |
| `task3_case_studies.json` | current corpus | Task 3 deliverable: 3 graph-path / caption-alignment studies |
| `retrieval_examples/` | current corpus | Task 4 deliverable: 10 caption → top-3 audio results |
| `checkpoints/<run>.pt` | stamped inside | best-epoch weights + their `provenance` |
| `plots/` | current corpus | curves, comparison, ablation, t-SNE, PR curves |

## Scoring a second corpus

Do not train a second corpus into the same `metrics.json` — it will raise
`ProvenanceConflict`. Give it its own results directory:

```bash
python src/train.py all --set dataset.source=gtzan --set paths.results=results_gtzan
```

## Regenerating the exports without retraining

```bash
python tools/export_deliverables.py --task task3 --mode cross_attention
```

## A note on the deleted file

`metrics_gtzan_baselines.json` was removed on purpose. It held GTZAN baselines
(150 test clips, 10 tags) in the same dict as Task 1/2/3 rows that were actually
from the synthetic run (90 clips, 32 tags) — a table built from it would have
read as GNN–BERT beating a CNN on GTZAN, which was never measured. The GTZAN
baselines survive in `metrics_gtzan.json` and the synthetic rows in
`metrics_synthetic.json`. The mandatory-provenance check in
`utils.merge_metrics` exists so this cannot recur.
